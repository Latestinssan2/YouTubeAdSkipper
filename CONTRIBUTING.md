# Contributing to YouTube Ad Skipper

Thanks for your interest in contributing! This document outlines the process for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/YouTubeAdSkipper.git`
3. Install dependencies: `npm install`
4. Build the extension: `npm run build`

## Development Setup

- **Node.js** (v16+)
- **npm** or **yarn**
- **Chrome browser** (for testing)

## Making Changes

1. Create a feature branch: `git checkout -b feature/my-feature`
2. Make your changes
3. Run the build: `npm run build`
4. Test in Chrome by loading the unpacked extension
5. Commit your changes: `git commit -m "Add my feature"`
6. Push to your fork: `git push origin feature/my-feature`
7. Open a Pull Request

## Code Style

- Use **TypeScript** for new files
- Follow the existing code style
- Add comments for complex logic
- Keep functions small and focused

## Testing

- Test in Chrome by loading the unpacked extension
- Verify on multiple YouTube pages (normal video, ad, etc.)
- Check the browser console for errors

## Pull Requests

- Keep PRs focused on a single feature or fix
- Describe what you changed and why
- Link any related issues
- Ensure CI passes
